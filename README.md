Entry for the [make.fun](https://make.fun/c/u-clever-harbor-75-one-star-for-monday-9ead4a61) competition
**"One Star for Monday"** — one original line, a one-star review of Monday
written as though Monday were a restaurant, at most 25 words.

## The entry

`main.ts` writes a single review line to `/output/entry.txt`:

> One star. Monday seated me by the toilets, served my motivation cold, and charged my whole week to the bill.

(20 words, 108 characters.)

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network.
